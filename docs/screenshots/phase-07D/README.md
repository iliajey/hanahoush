# Phase 7D Screenshot Reference

Captured from `http://localhost:5173/` at 1440×900px.

## How to capture

1. Start backend: `cd backend && python manage.py runserver`
2. Start frontend: `cd frontend && npm run dev`
3. Open `http://localhost:5173/`
4. For light mode: set theme to Light, capture full-page screenshots
5. For dark mode: set theme to Dark, capture full-page screenshots

## Required screenshots

| File | Section | What to capture |
|------|---------|-----------------|
| `home-top.png` | Full page (top 2000px) | Hero + Statistics + first services |
| `hero.png` | Hero section only | Animated headline, CTAs, grid background |
| `services.png` | Services section | 6 service cards in grid |
| `erp.png` | ERP section | Feature cards + module status |
| `projects.png` | Projects section | Project cards + technology chips |
| `footer.png` | Footer section | Multi-column footer |
