# Hanahoush — Frontend Documentation

Documentation home for the Hanahoush frontend (React + Vite + TypeScript).

| Architecture | [`docs/architecture/`](./architecture/) | High-level frontend architecture |

## Quick reference

```bash
# Dev server
npm run dev

# Type check
npm run typecheck

# Lint
npm run lint

# Tests
npm test

# Storybook (component browser)
npm run storybook

# Production build
npm run build
```
